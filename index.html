What does a backup include?

A backup contains plan values and additional sections, including saved fields that are currently hidden. It does not include evaluation results or original attachments: file names and references are saved, but the referenced files must still be available separately.

PDF and Word exports are documents to read or edit, not backups you can restore here. Calibration Save records feedback on an evaluation; Finish / Send submits a plan. Downloading or restoring a backup keeps the backup file local and does not send it anywhere.
