Research Plan

Your browser saves a draft automatically, but clearing browser data may delete it. Download a backup to restore your plan here later.

What does a backup include?

A backup contains plan values and additional sections, including saved fields that are currently hidden. It does not include evaluation results, calibration feedback or original attachments: file names and references are saved, but attachment contents are unavailable through this app.

Download backup saves a JSON file on your device. Downloading does not send your plan. To hand over a plan, deliberately share that file through the agreed private method and confirm receipt separately.

Restore backup replaces the current plan, including unsaved writing and hidden saved fields. Download a backup of your current plan first if you want to keep it. Cancel replacement if you have not done so. After restoration succeeds, edit the plan and download an updated backup to return privately.

Print / Save as PDF makes a readable copy; a PDF cannot be restored here. Browser autosave stays in this browser and site. Word export, Finish / Send and automatic synchronisation are unavailable.
